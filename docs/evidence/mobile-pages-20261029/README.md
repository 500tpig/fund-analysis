# 其余三页手机样板验收（2026-10-29）

范围：[第二批方案 2.3](../../mobile-ux-batch2-plan.md#23-其余三页铺样板)，仅涉及
`/holdings`、`/import`、`/simulation` 的字号、行高、表单间距、控件尺寸与状态反馈。
未修改业务逻辑或 API，未发布、未做真机验收。

## 环境与方法

- agent-browser 独立会话管理的 Chromium，访问 `http://127.0.0.1:8873` 的本轮 `frontend/dist`。
  视口为 390×844、430×932、768×1024、1440×900。
- 使用 `/tmp/fund-mobile-pages-20261029` 下的隔离 SQLite 持仓库与 fixture 模拟库，
  持仓包含长名称、大金额、负收益、现金和空基准日；模拟账户含已确认持仓、待净值订单、已完成订单及运行记录。
- 识图、基金检索与行情使用测试 provider，识图结果是人造候选，不调用外部识图服务。
  临时验收服务通过延迟与 503 响应覆盖加载和失败状态；暂停、恢复与录入确认只写入隔离库。
- 页面、抽屉或确认框打开后，扫描已布局的可见文字及表单输入的 computed font-size；
  扫描按钮、排序表头、可点击行、链接、输入与 summary 的命中区。检查包括滚动区域内的内容。
- 图标控件计入 `::after` 扩展区域；替换确认的复选框计入可点击的 label，保留 17 px 可视方框。
  桌面复制与行菜单另外通过 `elementFromPoint` 验证图标外区域仍命中控件，且 44×44 px 区域不跨行。
- 横向溢出同时检查 document 与当前工作区／抽屉 body 的 scrollWidth；没有用隐藏溢出的方式替代检查。
  页面操作通过浏览器输入执行，长内容先滚入可视区再点击；最后字段聚焦后核对其底边不超出固定操作栏顶部。

- `pnpm typecheck`、`pnpm lint`、`pnpm build` 及 `frontend/scripts/*.mjs` 全部 7 个脚本通过，
  包括曲线与抽屉返回栈回归。
