## 1. 本次改动

- 日样本改为追加候选，保留来源原值、前值与日期、真实报价时间、首次与最近采集时间、来源端点、
  选中点及相关模式字段。原始时间文本保留；比较使用解析后的时间。
- 唯一约束为 `(code, estimate_source, estimate_fingerprint)`。指纹已含规范化报价时间，
  因此与原方案相比，不再把原始时间文本重复放进唯一键，避免分钟／秒格式差异生成同一候选。
- 指纹只含估值净值与涨跌幅、前值与规范化前值日期、报价时间、境内归属规则是否确认、
  来源端点的主机与路径，以及 `PTYPE / field_pair / time_range / detail_page_type /
  zx_page_type / heavy_stock_us_flag`。名称、告警、描述、未选中的估值组、采集时间、URL
  批次参数均不生成新候选。重复采集保留首次证据并更新最近真实采集时间；首次采集时间异常时，
  后续有效采集可解除临时阻断，另存 `first_valid_fetched_at`，不覆盖首次异常时间。
- 各来源、跨午夜报价及同时间修订分别留存。同源旧报价不让最新表倒退；不同来源无可比时区时，
  最新表保留 provider 的当次来源选择，不用时间字符串决定优劣。摘要与最新展示分开。
- 归属只支持已确认的境内同日收盘规则及既有 Core / FundValuationLast 来源；报价按北京时间
  校验交易日、15:00–20:00 收盘窗口、真实采集时间。QDII 不实现成功归属分支，继续未知。
- 对账按净值日与来源选择最终收盘候选；同时间修订无法排序时全部排除，较新的基准冲突也不回退
  去选择误差更小的旧候选。对账读取已有官方存档，检查上一国内交易日、前值日期和数值、
  估值净值比及官方净值比。复用 `today_profit.assess_estimate_basis`，未另建估值模型。
- 前值净值容差为 0.00005；净值比与百分比一致性沿用已有 0.05 个百分点容差。
  不修改来源涨跌幅，不按历史误差修正未来报价。明显的分红／拆分或收益基准冲突会被排除；
  本次没有新增公司行动数据源，不能据此声明覆盖所有未披露的口径变化。
- 迟到报价以本次北京时间观察日留证，仍按真实报价日判断境内归属；官方延迟时等待对应日，
  不替换成最新日。官方更正或暂时请求失败时，重新检查已保存候选与可用存档。

没有新增 API 字段、依赖、来源请求、定时任务或 UI。复合 provider 仍只返回每次最终选中的点；
本次没有改成多来源同时采集，也不保存完整分钟数组。
